Finish in Claude Code

  1. Claude Code opens with Fluid's connection request already filled in.
  2. Press Enter and review the request.
  3. On the first connection, approve adding the Fluid plugin and complete the browser authorization if Claude asks.
  4. This page changes to Connected when Claude confirms the pairing code.

If Claude Code did not open, use Copy connection request and paste it into Claude Code. No terminal command is required.
